클로드 인 엑셀

Excel 환경에서 Claude AI를 활용하여 데이터 분석 및 자동화를 수행합니다.

⚡ 같은 요청을 사람이 작성한 프롬프트와 AI가 리팩토링한 프롬프트로 비교해보세요.
1
사람이 작성한 프롬프트
직관적이고 간결한 자연어 요청
▼
💡 일반 사용자가 자연스럽게 작성하는 방식의 프롬프트입니다. 핵심 요구사항을 간결하게 전달합니다.
프롬프트
# 역할 너는 제조업 품질관리 데이터 분석 전문가야. 철강 공장의 생산·품질 데이터를 다루는 데 익숙하고, 현장에서 실제로 쓸 수 있는 형태의 보고서를 만들 수 있어. # 맥락 동국제강 포항공장에서 판매하는 제품별 불량 현황을 파악하려고 해. 2024년과 2025년의 월별 추이를 비교해서, 품질 개선 여부를 확인하고 경영진에게 보고할 자료가 필요해. # 작업 * 동국제강 포항공장의 주요 판매 제품(형강, 철근, 평강, 환봉 등)에 대해 2024년~2025년 월별 불량 현황 데이터를 조사해줘. * 웹에서 실제 데이터를 찾을 수 없는 경우, 철강업계 현실에 맞는 가상 데이터를 생성해줘. * 이 데이터를 엑셀 파일(.xlsx)로 만들어줘. # 출력 형식 * 시트 구성: 연도별 시트(2024년, 2025년) + 요약 시트 * 항목: 제품명 / 월(1~12월) / 생산량(톤) / 불량수량(톤) / 불량률(%) * 수식: 불량률, 합계, 평균 등은 하드코딩 없이 Excel 수식으로 자동 계산 * 서식: 헤더 색상 구분, 천 단위 쉼표, 소수점 2자리 불량률, 제품별 행 구분이 명확할 것 * 2025년: 현재 시점 기준 3월까지만 데이터를 채우고, 4월 이후는 빈칸으로 남겨 추후 입력 가능하게 할 것 # 제약 조건 * 파일 하나로 완결되어야 하며, 별도 매크로 없이 일반 엑셀에서 바로 열 수 있어야 해. * 불량률은 제품별로 0.5%~5% 사이의 현실적인 범위로 설정해줘.
📌 시연 포인트: 간결한 프롬프트로도 Claude가 의도를 파악하고 엑셀 파일을 생성하는 과정을 보여주세요.

AI가 리팩토링한 프롬프트
구조화된 프롬프트 엔지니어링 적용
▼
💡 동일한 요청을 AI가 프롬프트 엔지니어링 기법으로 재구성한 버전입니다. 더 정확하고 일관된 결과를 기대할 수 있습니다.
프롬프트
# Role (역할 정의) 당신은 다음 두 분야의 최고 전문가입니다. 1. 제조업 품질관리(QC/QA) 데이터 분석 전문가 — 철강 공장 생산·품질 지표 설계 및 리포팅 경력 15년+ 2. Excel 데이터 모델링 전문가 — 제조 현장에서 즉시 활용 가능한 운영 보고서 설계에 정통 # Context (배경) - 동국제강 포항공장에서 판매하는 주요 제품의 품질 현황을 경영진에게 보고해야 함 - 2024년 실적과 2025년(1~3월) 실적을 월별로 비교하여 품질 개선 추이를 확인하는 것이 목적 - 실제 데이터가 웹에 공개되어 있지 않으므로, 철강업계 현실에 부합하는 가상 데이터를 생성할 것 # Task (작업 지시) ## 1단계: 데이터 설계 아래 대상 제품에 대해 월별 품질 데이터를 설계하시오. - 대상 제품: 형강(Section Steel), 철근(Rebar), 평강(Flat Bar), 환봉(Round Bar) - 데이터 항목: 제품명 / 월(1~12월) / 생산량(톤) / 불량수량(톤) / 불량률(%) - 불량률 범위: 제품별 0.5%~5% (철강업계 현실 반영) - 데이터 특성: 계절적 변동, 설비 정비 주기, 제품별 난이도 차이를 반영한 현실적 패턴 ## 2단계: Excel 파일 작성 설계한 데이터를 .xlsx 파일로 작성하시오.
시트 구성
시트 구성 내용
1 2024년 제품별 월간 생산량·불량수량·불량률 (1~12월 전체)
2 2025년 제품별 월간 데이터 (1~3월 입력, 4~12월 빈칸 — 추후 입력용)
3 요약(Summary) 연도별·제품별 합계, 평균 불량률, YoY 비교 지표
서식 기준
# 서식 기준 (Formatting) - 헤더: 동국제강 CI 컬러(#003A78) 배경, 흰색 텍스트, 굵게 - 숫자: 생산량·불량수량은 천 단위 쉼표(#,##0), 불량률은 소수점 2자리(0.00%) - 수식: 불량률 = 불량수량 ÷ 생산량 × 100 (하드코딩 금지, Excel 수식으로 자동 계산) - 합계·평균: SUM / AVERAGE 함수 사용, 연간 합계 행 포함 - 구분: 제품별 행 그룹에 교대 배경색 적용, 테두리로 명확히 구분
Output (산출물)
# Output (산출물) - 최종 산출물: .xlsx 파일 1개 (3개 시트) - 파일명 예시: 포항공장_제품별불량현황_2024-2025_YYYYMMDD.xlsx # Constraints (제약 조건) - 파일 하나로 완결, 별도 매크로(VBA) 없이 일반 Excel에서 바로 열 수 있을 것 - 2025년 시트는 4월 이후 빈칸으로 두어 현장에서 직접 데이터 추가 입력 가능하게 할 것 - 요약 시트의 모든 지표는 원본 시트를 참조하는 수식으로 구성 (하드코딩 금지)
📌 시연 포인트: 구조화된 프롬프트가 어떻게 더 정밀한 결과물을 만들어내는지 V1과 비교하여 보여주세요.

프롬프트
#역할 * 너는 최고의 국제정세 전문가야. * 또한 철강 산업에 대한 전문 지식이 25년 이상 있어. #맥락 * 최근 발생한 미국과 이란의 전쟁 상황을 분석하고 한국 철강 산업 특히, 철근 산업에 미치는 영향에 대해서 상세히 알고 싶어. #작업 * 관련 자료를 웹을 통해서 자료를 수집하고 정리해줘. * 정리한 자료는 PPT로 작성해줘. * PPT는 5장 이내 임원 보고용으로 작성 * 제목 1페이지, 목차 1페이지, 내용 3페이지 분량으로 작성 * 동국제강 그룹 디자인 양식으로 작성 (색상, 폰트 등)

AI가 리팩토링한 프롬프트
구조화된 프롬프트 엔지니어링 적용

💡 동일한 요청을 AI가 프롬프트 엔지니어링 기법으로 재구성한 버전입니다. 더 정확하고 일관된 결과를 기대할 수 있습니다.
프롬프트
# Role (역할 정의) 당신은 다음 두 분야의 최고 전문가입니다. 1. 국제정세 분석 전문가 — 중동 지정학, 에너지·원자재 시장 파급효과 분석 2. 철강 산업 전문가 (경력 25년+) — 글로벌 철강 밸류체인, 한국 철근(Rebar) 시장 구조에 정통 # Context (배경) - 2026년 미국-이란 간 군사적 충돌(전쟁) 상황이 발생하였음 - 이로 인해 국제 원자재 시장, 해상 물류, 에너지 가격 등에 연쇄적 영향이 예상됨 - 본 보고서는 동국제강 그룹 경영진의 의사결정을 지원하기 위한 긴급 브리핑 자료임 # Task (작업 지시) ## 1단계: 정보 수집 (Web Research) 아래 항목에 대해 최신 웹 자료를 검색·수집하시오. - 미국-이란 전쟁 현황 및 향후 시나리오 (확전/제한전/협상 등) - 국제 유가·원자재(철광석, 고철, 원료탄) 가격 동향 및 전망 - 글로벌 해상 물류 리스크 (호르무즈 해협 봉쇄 가능성, 운임 변동) - 한국 철강 산업, 특히 철근(Rebar) 시장에 미치는 직·간접 영향 - 국내 건설 경기 및 철근 수급 전망과의 연계 분석 ## 2단계: PPT 작성 수집한 자료를 바탕으로 임원 보고용 PPT(5페이지)를 작성하시오.
슬라이드 구성
페이지 구성 내용
1 표지 제목, 부제, 보고 일자, 작성 부서
2 목차 본문 3개 섹션 요약 + 페이지 번호
3 정세 분석 미-이란 전쟁 현황, 시나리오별 전개 전망
4 산업 영향 원자재·물류·철근 가격 파급 경로 및 영향도 분석
5 시사점 및 대응 동국제강 관점의 리스크 요인 및 의사결정 포인트
작성 기준
# 작성 기준 - 언어: 한국어 본문 + 영어 병기 (주요 용어, 차트 레이블 등) - 톤: 경영진 의사결정용 — 핵심 메시지 중심, 장황한 서술 배제 - 디자인: 동국제강 그룹 CI 기반 · Primary Color: 동국제강 블루 (#003A78) / Accent: (#E63312) · 폰트: 본문 맑은 고딕 / 영문 Arial 또는 Pretendard · 깔끔한 도표·차트 활용, 슬라이드당 핵심 메시지 1개 원칙
Output (산출물)
# Output (산출물) - 최종 산출물: .pptx 파일 1개 (5슬라이드) - 파일명 예시: 미이란전쟁_철근산업영향_임원보고_YYYYMMDD.pptx
